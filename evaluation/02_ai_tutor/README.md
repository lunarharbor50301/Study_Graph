# AI Tutor

single_turn仅列题目ID，标准答案统一在shared/question_bank.json；multi_turn每份课件3段，每段4轮。

多轮按顺序发送，每段新建会话，段内保留真实历史回答。不能只传相同session_id却丢弃历史。错误回答可能影响后续；按用户原意评分，并记录前序错误传播。当前脚本未实现多轮运行；正式执行需UI或真正传递历史的接口。

逐轮评要点、指代/条件保持、话题切换及引用。每段必需点全部满分且无事实矛盾才算严格成功；分别报告轮次得分与整段成功率。引用跳转需实际点击/请求验证；未验证标记未测，不能仅凭输出有页码计成功。

唯一指标定义：[共用评分规范 v1.0](../shared/scoring.md)。分母为0记N/A，未执行检查记未测；失败不能静默剔除。
