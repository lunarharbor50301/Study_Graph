# 后端概念图生成改进与英文评测迭代

2026-11-19 · `yxy-v3` · ACS Lecture 1（67 页）与 Lecture 2（69 页）

最新一轮采用英文参考集 `v0.5-en`。L1 最终生成 24 个节点，覆盖 17/17 个参考概念；L2 生成 29 个节点，覆盖 19/19 个参考概念。两张图的节点页码均连续，136 个物理页逐页核对后全部有归属。本次两份讲义中只有 L2 首次生成成功，L1 在同样输入下重试一次才通过校验。

## 1. 后端生成流程如何变化

1. **一次生成整张图 → 先定大纲、再分批写笔记。** 早期流程从讲义摘录一次生成主题和笔记，最多 5 个主题、每个主题 4 个概念。分阶段版本取消了固定的 20 节点上限，先给模型整份讲义的逐页索引，再按大纲分批读取正文。它提高了长讲义的核心覆盖，但也容易把一个机制的定义、示例和后果拆成多个节点。
2. **用学习问题决定节点粒度。** 每个大纲节点增加 `learning_question` 和 `evidence_pages`，同时保留一个用于跳转的主引用页 `page`。相邻页面若共同回答同一学习问题，可以一起写成一份笔记。补漏移到写笔记之前，先尝试把页面归入已有节点，再考虑新增节点。网页也接收完整的来源页列表，学生可以直接看到跨页范围。
3. **限制每个节点的页码连续。** 大纲阶段检查主引用页是否属于来源页、来源页是否逐页连续；补漏阶段也检查追加后的完整区间。举例来说，第 66–67 页可以共同讲 CXL 扩容和池化，第 63、66 页不能直接拼成一个节点。
4. **要求最终输出覆盖每一个物理页。** 大纲补漏后检查一次；笔记写完后，再对实际返回的节点检查一次。预算允许时，只重试未生成有效笔记的节点。仍有漏页则返回 HTTP 502 并列出页码。封面、导读、分隔页作为相邻教学段的上下文；即使是少字页，也不能从最终图中消失。生成缓存已按版本区分。

## 2. 用同一版参考集观察生成逻辑变化

下表均使用 `v0.4-en`。核心覆盖分母为每份讲义的 20 个参考概念。笔记均分先对每份参考笔记归一化，再对笔记等权平均。表内各次生成节点的自动判定准确率均为 100%。

| 生成方式 | 讲义 | 生成节点 | 核心覆盖 | 图内笔记均分 | 满分笔记要点 |
|---|---|---:|---:|---:|---:|
| 一次生成，20 节点上限 | L2 | 20 | 8/20 | 34.17% | 15/52 |
| 分阶段生成，默认配置单次记录 | L2 | 54 | 20/20 | 96.25% | 48/52 |
| 分阶段生成，L1/L2 成对测试 | L1 | 52 | 20/20 | 94.58% | 44/48 |
| 同上 | L2 | 47 | 19/20 | 88.75% | 45/52 |
| 按学习问题合并，多页证据 | L1 | 29 | 19/20 | 90.83% | 43/48 |
| 同上 | L2 | 28 | 19/20 | 87.92% | 43/52 |

以成对测试为基线，加入学习问题后，L1 节点从 52 降至 29，减少 44%；L2 从 47 降至 28，减少 40%。L1 少覆盖一个参考概念，笔记均分下降 3.75 个百分点；L2 覆盖总数持平，笔记均分下降 0.83 个百分点。L2 两次分阶段基线本身也有差异，单次得分还不足以估计稳定性。

## 4. 评测口径与复算

最新一轮在独立后端、空概念图缓存下使用默认整份讲义要求，由 DeepSeek Flash 生成，英文参考集仅在评分阶段提供给裁判。笔记评分针对随图返回的内容；每条参考要点按缺失或错误、部分覆盖、完整覆盖分别计 0、1、2 分。页码检查使用同一生成结果的 `guide.json` 中每条笔记的 `evidence_pages`。语义分数由模型自动判定，两份参考集仍待人工复核。此次未评语义关系。

在仓库根目录运行以下命令，可用保存的裁判明细复算最新两份语义成绩，无需模型调用。脚本要求输出路径尚不存在。

```bash
for i in 1 2; do
  d="evaluation/results/v0.5-en-20261119/l$i"
  .venv/bin/python -m evaluation.runners.knowledge score \
    --reference "evaluation/01_knowledge/v0.5-en/lecture$i.json" \
    --prediction "$d/prediction.json" --review "$d/review.json" \
    --output "$d/metrics-recomputed.json"
done
```
