Cache hits and misses

Concept facts

  • A hit requires a valid matching block at this cache level.
  • Miss rate equals one minus hit rate.
  • A miss requires service from a lower level.

TLB misses versus cache misses

Concept facts

  • A TLB miss requires address translation work.
  • A cache miss requires fetching data from a lower level.
  • A translation miss and a data miss are distinct events.
Lecture evidence · p. 30

Core concept · sram-dram

SRAM versus DRAM

Concept facts

  • SRAM retains state in a stable transistor circuit and is used in caches or registers.
  • DRAM stores charge in capacitors, needs refresh and restores data after reading.
Lecture evidence · p. 32
SRAM --- Store data via stable transistor circuit Requires low power to retain bit (423mV for 45nm) Requires 6 transistors/bit --- expansive Usage: Caches, register files DRAM --- Store date via tiny capacitors (bit is represented as charged and discharged) One transistor/bit --- cheap Must be re-written after being read Must also be periodically refreshed Each row can be refreshed simultaneously Address lines are multiplexed: Upper half of address: row access strobe (RAS) Lower half of address: column access strobe (CAS) Usage: DDR / GDDR / HBM CPU Memory Hierarchy DRAM Behind Cache: SRAM vs. DRAM Memory Wall CPU Memory GPU Memory SOTA Memory Advanced AI Computing and Systems 32

Core concept · coalescing

Memory coalescing

Concept facts

  • Coalescing applies to one memory instruction issued by a warp.
  • Aligned contiguous addresses usually reduce transactions.
  • Strided accesses or boundary crossings can increase transactions.
Lecture evidence · p. 48
GPU Memory Hierarchy Access Memory: Coalescing Packs Nearby Addresses into Fewer Transactions Coalescing is evaluated for one warp memory instruction. Aligned, contiguous addresses touch fewer segments. ▪ Misalignment can cross extra boundaries. Strided accesses can touch many more segments. ▪ Memory Wall CPU Memory GPU Memory SOTA Memory Advanced AI Computing and Systems 48
