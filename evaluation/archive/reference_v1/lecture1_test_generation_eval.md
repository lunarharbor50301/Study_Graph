### L1-ANSWER03
数据、控制和结构冒险有什么区别？

### L1-ANSWER09

### execution
仅把 input 发给被测 agent；expected、reference、rubric、grading_key 均留在评测端。出题后先冻结输出，再独立审核其答案，不能以系统自带答案作为真值。

### fair_comparison
两系统使用相同模型、单份PDF、提示、参数和预算。逐题独立会话；完整保存输入输出、模型版本、耗时、失败。失败单列并按预先规则计0，不静默剔除。

### split
按topic_family分组，先冻结开发/测试划分；同主题的出题、回答、批改变体不得跨组。当前为未划分候选集。

### human_review
候选标准由助手制定，尚未经人工审核；至少两名成员对部分样本盲评、处理分歧后冻结。


套题跨多个主题：划分时应将相连主题整体分组，或仅把套题任务放开发集，避免泄漏。
