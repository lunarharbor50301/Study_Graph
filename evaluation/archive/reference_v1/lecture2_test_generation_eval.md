## 三、回答固定问题

### L2-ANSWER12
区分空间局部性和时间局部性。
参考：空间局部性是邻近数据可能被访问；时间局部性是同一数据短期内被复用。
评分点：空间局部性是邻近数据可能被访问；时间局部性是同一数据短期内被复用
证据页：22

### L2-ANSWER13
写出 AMAT 公式，并解释 miss penalty。
参考：AMAT=hit time+miss rate×miss penalty；miss penalty 包含访问延迟和传输时间。
评分点：AMAT=hit time+miss rate×miss penalty；miss penalty 包含访问延迟和传输时间
证据页：26

### L2-ANSWER14
TLB miss 和 cache miss 是同一件事吗？
参考：TLB miss 涉及地址翻译；cache miss 涉及从更低层获取数据；两者不同。
评分点：TLB miss 涉及地址翻译；cache miss 涉及从更低层获取数据；两者不同
证据页：30

### L2-ANSWER15
比较 SRAM 和 DRAM 的存储方式及典型用途。
参考：SRAM 用稳定晶体管电路保存状态，常用于缓存和寄存器；DRAM 用电容保存数据，需要刷新和读取后恢复。
评分点：SRAM 用稳定晶体管电路保存状态，常用于缓存和寄存器；DRAM 用电容保存数据，需要刷新和读取后恢复
证据页：32

### L2-ANSWER16
增加 bank 后，一个通道的返回带宽是否无限增长？
参考：独立 bank 的工作可以重叠；共享数据总线仍限制同时返回的数据量。
评分点：独立 bank 的工作可以重叠；共享数据总线仍限制同时返回的数据量
证据页：36

### L2-ANSWER17
DDR5 两个 32 位子通道是否意味着总位宽翻倍？
参考：独立通道并发使用可增加带宽；DDR5 将 64 位分成两个 32 位子通道不会单独使总位宽翻倍。
评分点：不翻倍；两个32位子通道合计仍为64位
证据页：40

## 切换 TACC / DeepSeek 运行评测

以下是当前代码的运行方式，历史报告中的模型名称和成绩保持原样；切换模型后应保存到新的结果目录并重新评分。[完整配置、参数和运行说明](../../runners/README.md)。命令均从仓库根目录执行。

先启动 TACC 模型及 SSH 隧道，然后在运行评测脚本的终端设置地址并检查接口：

```bash
export QWEN_BASE_URL=http://127.0.0.1:18024/v1

curl --noproxy '*' -fsS --max-time 8 \
  http://127.0.0.1:18024/v1/models
```

直接调用 TACC 的评测脚本不需要 DeepSeek API key。改用 DeepSeek 时，需要在当前进程配置 `DEEPSEEK_API_KEY`。如果密钥已保存在项目 `.env` 中，可以加载：

```bash
set -a
source .env
set +a
```

本文件属于历史归档，不应直接套用旧题集或旧命令进行新版比较。当前出题入口使用 `--provider tacc`（可另设 `--judge-provider deepseek`），批改入口使用 `--provider tacc`，概念图语义评分使用 `--judge tacc`。换成 `deepseek` 可使用对应 DeepSeek 接口；当前题集及完整命令见上面的运行说明。
