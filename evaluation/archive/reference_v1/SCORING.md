# 单课件共用评分说明

只导入目标 JSON 的 document 对应 PDF；用 SHA256 验证文件版本。页码为从 1 开始的 PDF 物理页码。所有数据均待团队人工审核。

- 概念：按同义词归一化后评正确性与核心覆盖率；参考集之外的有效概念人工复核，不自动判错。
- 关系：检查起点、终点、方向与关系语义；单课件测试不使用 cross_lecture_relations_optional.json。
- 笔记与问答：逐要点评分，0=缺失或错误，1=部分正确，2=完整正确。接受中英文等价表述；额外实质错误单独记录。
- 引用：检查文件、物理页码、引用对结论的支持性和引用完整性。已列证据页不是唯一允许页；其他有效页面需核实。
- 批改：分别评正确、不完整、错误类别及误报；不能把遗漏当作错误陈述。当前示例未给人工逐点得分，正式评测前补齐。
- 无证据题：承认缺少运行时数据，不编造，并说明需要什么测量。不要因没有引用而惩罚合理拒答。
- 数据划分：同概念、计算变体和学生答案作为同一题目家族；强关联知识点也应分组。正式调试前冻结开发/测试划分。
- 汇总：先分别报告各课件的分项分数和样本数，再报告等权宏平均或按样本数加权平均，明确方法。两份文件共用的无证据题属于重复场景，不能声称为不同独立问题。
- 基线与 agent 使用相同模型、单份 PDF、题目及预算；随机隐藏系统名称进行人工评分。

本版未覆盖全部课件知识，未包含完整多轮任务、完整生成题目质量测试及人工评审成绩。

## 切换 TACC / DeepSeek 运行评测

以下是当前代码的运行方式，历史报告中的模型名称和成绩保持原样；切换模型后应保存到新的结果目录并重新评分。[完整配置、参数和运行说明](../../runners/README.md)。命令均从仓库根目录执行。

先启动 TACC 模型及 SSH 隧道，然后在运行评测脚本的终端设置地址并检查接口：

```bash
export QWEN_BASE_URL=http://127.0.0.1:18024/v1

curl --noproxy '*' -fsS --max-time 8 \
  http://127.0.0.1:18024/v1/models
```

直接调用 TACC 的评测脚本不需要 DeepSeek API key。改用 DeepSeek 时，需要在当前进程配置 `DEEPSEEK_API_KEY`。如果密钥已保存在项目 `.env` 中，可以加载：

```bash
set -a
source .env
set +a
```

本文件属于历史归档，不应直接套用旧题集或旧命令进行新版比较。当前出题入口使用 `--provider tacc`（可另设 `--judge-provider deepseek`），批改入口使用 `--provider tacc`，概念图语义评分使用 `--judge tacc`。换成 `deepseek` 可使用对应 DeepSeek 接口；当前题集及完整命令见上面的运行说明。
